ALMaSS Subpopulation Model {#mainpage}
=========

For some insects, e.g., aphids, the very high population size and lack of detailed individual behaviour information make agent-based approaches either computationally expensive or infeasible. In addition, these insects may be modelled as a prey base for other species, e.g. ladybirds, requiring a relatively easy way to model these species accurately. A subpopulation-based method was integrated into ALMaSS to solve the issues of high density and computational complexity. The implementation of the general subpopulation model within ALMaSS is achieved through the definition of two C++ classes. The “Subpopulation” class represents a single subpopulation in a grid, and an object of this class is used to simulate the stage-structured subpopulation in each grid cell (default 10m×10m area). The “Subpopulation_Population_Manager” class is an administrative class that manages the entire population in the simulated landscape comprised of all Subpopulation objects and provides the input/output functions for the subpopulation model.

These two classes include all the necessary code to implement the subpopulation model, which can then be integrated into the standard ALMaSS landscape simulation model when an instance of the model is created. The ALMaSS landscape simulation model provides the modelled species with landscape-contextual information dynamically as the simulation runs. Further, the ALMaSS subpopulation modes can run in parallel in the thread level using OpenMP.
