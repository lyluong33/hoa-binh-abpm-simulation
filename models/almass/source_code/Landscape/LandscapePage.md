ALMaSS Landscape Model {#mainpage}
=========

The Landscape class is a large, multifaceted class that provides the central interface for accessing environmental information within ALMaSS agent-based and subpopulation models. This class is essential to ALMaSS simulations, as it is initialized at the start and establishes core data structures and classes. Key functions include: <br>

- Map Representation: Creates the internal representation of the map and its associated classes.
- Farm Management: Sets up the FarmManager class and handles all farm-related information.
- Habitat Development: Simulates habitat patch evolution, including vegetation modelling.
- Species Behaviour Support: Provides miscellaneous functions that aid in implementing species behaviour within models.
- Data Modification and Output: Allows for the modification of input data and the generation of output for further analysis.
